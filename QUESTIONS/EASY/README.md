Welcome to the **Easy Java Questions** section of this repository! 🚀

## 💡 Recommended Way to Practice

Don't immediately look at the solution.

Try this process:

```text
1️⃣ Read the problem
       ↓
2️⃣ Understand the input
       ↓
3️⃣ Think about the logic
       ↓
4️⃣ Write the Java code
       ↓
5️⃣ Run the program
       ↓
6️⃣ Test different inputs
       ↓
7️⃣ If stuck → check the solution
       ↓
8️⃣ Understand why it works
```

### 🧠 Remember

**The goal isn't to finish all the questions quickly.**

The goal is to understand the **logic behind each solution**.
